  パチ戦記 ― 放置バトルパチンコ ―
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ダウンロードありがとうございます!
玉が釘を転がり、スタート口でスロットが回り、大当たりで英雄たちが敵をなぎ倒す
「放置バトルパチンコ」です。放置しているだけで激アツ演出が飛び出します。

■ 遊び方
 1. 「pachi-senki.html」をダブルクリック(ブラウザで開きます)
 2. 「START」を押すとゲーム開始(音が出ます)
 3. あとは放置でOK。盤面をタップすると玉を追加、戦闘画面をタップすると追撃、
    宝袋や流れ星をタップすると捕まえられます
 4. 左下のメニュー(三本線)から 強化・転生・図鑑・遺物・鍛冶屋・ランキング などを見られます

■ 動作環境
 ・PC: Chrome / Edge / Safari / Firefox の最新版
 ・スマホ: iPhone(Safari)/ Android(Chrome)
   ※スマホは、ファイルアプリ等から HTML を開いてください
 ・インターネット接続は不要です(フォントの取得にだけ使い、つながらなくても遊べます)

■ セーブについて
 ・自動でブラウザ内に保存されます
 ・ブラウザの履歴/サイトデータを消すとセーブも消えます
 ・別のブラウザや、HTML の置き場所を変えるとセーブは別になります

■ ご注意
 ・画面のフラッシュ(点滅)があります。光に敏感な方は、メニュー横の設定で
   フラッシュを「弱」または「OFF」にしてください
 ・音量にご注意ください(設定で BGM / 効果音を調整できます)
 ・ゲーム内のお金はすべて架空のものです。実際のお金を賭けたり換金したりする要素はありません

■ 応援について
 このゲームは無料です。気に入ってもらえたら、BOOTH の「BOOST」や「応援版」で
 応援してもらえるととても励みになります。応援版に入っている「サポーターコード」を
 ゲーム内メニュー「応援」で入力すると、タイトルに★が付きます(ゲームが有利になることはありません)。

■ 禁止事項
 ・このゲームの無断再配布、販売、改変したものの配布
 ・ゲームの画像やイラストの無断転載
