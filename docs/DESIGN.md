# 退屈させない設計メモ(新しい機能を作る前に読む)

ゲームデザインでよく使われる考え方を、このゲームに当てはめたもの。機能を足す時は最後のチェック表を通す。
(出典は一般に知られた理論。ネットで調べ直したものではなく、内容は要点だけ)

## 1. 考え方と、このゲームでの使い方
| 考え方 | 中身 | このゲームでは |
|---|---|---|
| フロー(チクセントミハイ) | 難しさが腕前とつり合うと夢中になる。易しすぎ=退屈、難しすぎ=不安 | 序盤は順当 → 中盤から守りを育てないと詰まる(94c)。全滅しても1つ戻るだけ+リベンジで必ず越えられる |
| 自己決定理論(自律・有能・関係) | 自分で選べる/上達を感じる/キャラへの愛着 があると続く | 自律=育て方と衣装を選ぶ、有能=「次のボスで約○秒もつ」が伸びる、関係=3人+ツララの会話と性格(STORY.md) |
| 変動報酬(当たるか分からない) | いつ来るか分からないごほうびは強い。ただし「はずれ」ばかりは疲れる | 大当たり・JACKPOT・押せ!!の熱さ。天井(ハマり救済)で長いはずれを作らない |
| 目標勾配(ゴールが近いほど頑張る) | 残りが見えると続ける | 進み具合を数字で出す(衣装「JACKPOT 7/10」、実績、図鑑、塔の「次の加護 20階」) |
| 短・中・長の目標の重ね | 数秒〜数分〜数日の目標が同時にあると、どの瞬間もやることがある | 短=大当たり/ボス、中=エリアの主/仲間の加入/衣装、長=転生/塔/エンディング/2周目 |
| 新しさのペース(興味曲線) | 一定の間隔で「新しい物」が出ると飽きにくい。山と谷をつける | だいたい25ステージごとに エリア・主・会話・新要素(下の解放表) |
| 役割のちがい | 同じ強さの足し算だけだと選ぶ意味が無い | ツララ=装甲つらぬき、妖精=回復、雷鳥=敵の手を止める、剣士=かばう |
| 収集と完成 | そろえる楽しみ。ただし数だけ増やすと作業になる | 図鑑・遺物・衣装。衣装は少数で、1つずつ手に入れ方を変える |
| 見せびらかし・自己表現 | 自分だけの見た目は長く遊ぶ理由になる | 衣装、称号、筐体テーマ(性能は変えない) |

## 1b. 「また遊びたくなる」ための考え方(何回も戻ってきてもらう)
| 考え方 | 中身 | このゲームでは |
|---|---|---|
| 習慣の輪(きっかけ→行動→ごほうび) | 毎回同じ小さな手順があると、開くのが習慣になる | 開く → おみくじを引く(98o)・ログボ・遠征の受け取り・ミッション。どれも数秒で終わる |
| 自分で引く変動報酬 | 自動でもらうより、自分で引いた方がうれしい | おみくじは自分で引く(大吉/中吉/小吉)。勝手には付かない |
| やりかけ効果(ツァイガルニク) | 途中の物は気になって戻ってくる | 「次の目標」(98o)が、もうすぐ届く物を進み具合つきで見せる。遠征の残り時間 |
| 約束の時間 | 「あとで戻ると良いことがある」が戻る理由になる | 遠征(30分〜16時間)、ボーナスタイムのゴールデンタイム、おかえりボーナス |
| 積み上げたものへの愛着(投資) | 自分で育てた・選んだ物があるほど離れにくい | 衣装、音楽室で選んだ曲、育てた英雄、図鑑・遺物 |
| 自己ベストの更新 | 他人と比べなくても、昨日の自分を超えるのは楽しい | 最高ステージ、塔の階、RUSH の連チャン記録、ランキング |
| 終わりよければ(ピーク・エンドの法則) | 一番盛り上がった所と最後の印象で記憶が決まる | 山場=JACKPOT/エリアの主。やめる時に「次はこれ」が見える(次の目標) |
| あおらない | 「今やらないと損」は短期では効くが、疲れて離れる原因になる | おみくじは引かなくても損なし・連続日数が切れても罰なし・期間限定で急がせない |

毎日のきっかけは増やしすぎない(開くたびにやる事が5つも6つもあると義務になる)。今は ログボ(自動)・おみくじ・ミッション・遠征 の4つ。これ以上は足さず、中身を良くする。

## 1c. ドット絵の考え方(英雄の絵を描く・直す時)
調べた資料: [Lospec: Pixel Art Outlines (using color)](https://lospec.com/articles/pixel-art-outlines-part-2-using-color) / [Pixel Parmesan: Anti-Aliasing Fundamentals](https://pixelparmesan.com/anti-aliasing-fundamentals-for-pixel-artists) / [pixnote: Shading & Lighting](https://pixnote.net/en/learn/shading) / [pixnote: Characters](https://pixnote.net/en/learn/character)
| 考え方 | 中身 | このゲームでは(10-sprites の mkH2) |
|---|---|---|
| 光の向きを1つに決める | 光は左上、影は右と下。全員そろえる | 髪・帽子の左上に光の色、右側に影の色。額に前髪の影 |
| 色のまとまり(ランプ) | 素材ごとに 影・基本・光 の3色まで。32px では段を増やすとうるさい | mat=[輪郭の文字,'基本・影・光'] |
| 色相ずらし | 影は暗くするだけでなく青紫寄りに、光は黄寄りに | 赤い髪の影=赤紫、光=橙。肌の影=赤寄り |
| 選択的な輪郭 | 輪郭を真っ黒にせず、となりの素材の暗い色に。影の側だけ濃く | 輪郭 k を自動で塗り分け(外側の右・下と目のふちは濃いまま) |
| 明るさの差で読ませる | 色より明暗の差。目を細めても部分が分かれるか | 肌と髪、服と腕の明暗をはっきり |
| シルエット | 黒く塗りつぶしても誰か分かる形に | ツンツン髪 / とんがり帽子 / フード / 長い髪 + 武器 |
| ぼかさない | 小さい絵では輪郭をなめらかにしない。1ドットの位置で印象が変わる(特に目) | 目は 2x2 + まゆ。拡大は必ず整数倍(32px を2倍) |
| 武器と体を一緒に動かす | 武器は必ず手の先、手は腕、腕は肩につながる。構え(武器を引く・腰を落とす)→ 攻撃(踏み込む・腕を伸ばす・軌跡)の順。待機の腕のまま武器だけ動かさない | 構え/攻撃のコマは下ろした腕を消して肩から描き直す('_')。横48で伸ばした腕と武器が入る。攻撃中の英雄は手前に描く |

## 1d. エフェクトの考え方(84c 攻撃エフェクト、98r 転生の演出)
| 考え方 | 中身 | このゲームでの使い方 |
|---|---|---|
| 予兆 → 発生 → 余韻 | 始まる前に小さな合図、発生は1〜2コマで一気に最大、消える時は破片や輪が残って散る。出しっぱなしにしない | 武器の先がキラッ(0.08秒)→ 白い大きな光 → 破片が重力で落ちる |
| 同じ瞬間に重ねる | 光る・形・破片・輪・音・(重い時だけ)止め/揺れ を同時に | 命中: 白い光+形+破片+放射の線+英雄ごとの音 |
| 明るさの差 | 中心は白、外へ濃い色。まわりより明るい所に目が行く | 3色: 白 → 英雄の明るい色 → 濃い色 |
| 形で伝える | 形だけで誰の何か分かる | 剣=弧と線 / 魔法=輪と星 / 矢=直線 / 槍=ひし形 |
| 大きさは重さ | 大事な一撃ほど大きく長く。ふだんは控えめにして差を出す | 会心 x1.5、RUSH 中 x1.2 |
| 揺れ・止めは控えめ | ずっと揺らすと疲れる。決定的な一撃だけ | 攻撃エフェクトでは画面を揺らさない(大当たり等にまかせる) |
| 抽選に触れない | 見た目の機能がゲームの乱数を使うと当たりの出方が変わる | ばらつきは時刻から作る(Math.random を使わない) |

参考: [VFX のタイミング](https://www.vfxapprentice.com/blog/the-soul-of-effects-what-is-timing-in-vfx) / [LoL の VFX 指針の要約](https://www.vfxapprentice.com/blog/10-league-of-legends-vfx-design-tips) / [ドット絵とアニメの原則](https://www.sprite-ai.art/guides/animation-principles) / [当たった感じの作り方](https://uhiyama-lab.com/ja/notes/ue/game-feel-hit-feedback/) / [手応えのある戦闘](https://www.wayline.io/blog/making-combat-feel-impactful)

## 1e. 音の考え方(75 / 77 / 79、作り手の指摘「もっと重厚に・聴いて気持ちいい音に」)
| 考え方 | 中身 | このゲームでの使い方 |
|---|---|---|
| 重ねて作る | 大事な瞬間は 低音・形のある音・きらめき・響き を同じ瞬間に重ねる。1本の音では細い | `sBoom`(ドン)+ `sFat`(厚い金管)+ `sBell`(鐘)+ 響き |
| 低音は体で聴く | パチンコ店の大当たりは「ドン」という重低音が体に来る。50〜150Hz の下がる音と低い雑音 | 大当たり・JACKPOT・押せ!!・激アツ・ボス は `sBoom`、強さは重要度で変える |
| 機械の手応え | 実機はリールや役物が「ガコン」、玉は金属の「チャリ」、ボタンは振動する | `sClunk` / `sMetal` / `sBuzz` |
| 差で気持ちよく | ふだんの音まで派手にすると疲れて、大当たりが目立たない | 命中・コンボ・保留は短く小さく(低音は雑音で少しだけ)。発音数の上限 tests/audio.js |
| 耳に痛い高域を丸める | ノコギリ波そのままは「キンキン」する | 暖かい経路 `wm`(低域通過)を通す |
| 調(キー)に合わせる | 効果音の音程は今の BGM の調から作る(不協和にしない) | `fanRoot` / `sLad` / `sRise` / `beep` の音階丸め |
| 抽選に触れない | 音がゲームの乱数を使うと、音を変えただけで当たりの出方が変わる | 音の乱数は `sR()` |

## 3. 新しい機能のチェック表
- [ ] 何の退屈をなくすのか、1行で言えるか(上の表のどれに当たるか)
- [ ] 既にある物と役割がかぶっていないか(同じ「ダメージ+○%」をもう1つ足すだけになっていないか)
- [ ] 手に入るまでの進み具合が画面に出るか
- [ ] 解放の表の「空いている所」に置いたか
- [ ] 放置でも進むか(操作を強制しない)。触ると少し得、くらいにとどめる
- [ ] 買わない方が得になっていないか(sim で 買う/買わない を比べる)
- [ ] 不安をあおる作り(期間限定で急がせる・失うのが怖い)にしていないか
