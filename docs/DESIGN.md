# 退屈させない設計メモ(新しい機能を作る前に読む)

ゲームデザインでよく使われる考え方を、このゲームに当てはめたもの。機能を足す時は最後のチェック表を通す。
(出典は一般に知られた理論。ネットで調べ直したものではなく、内容は要点だけ)

## 1. 考え方と、このゲームでの使い方
| 考え方 | 中身 | このゲームでは |
|---|---|---|
| フロー(チクセントミハイ) | 難しさが腕前とつり合うと夢中になる。易しすぎ=退屈、難しすぎ=不安 | 序盤は順当 → 中盤から守りを育てないと詰まる(94c)。全滅しても1つ戻るだけ+リベンジで必ず越えられる |
| 自己決定理論(自律・有能・関係) | 自分で選べる/上達を感じる/キャラへの愛着 があると続く | 自律=育て方と衣装を選ぶ、有能=「次のボスで約○秒もつ」が伸びる、関係=3人+ツララの会話と性格(STORY.md) |
| 変動報酬(当たるか分からない) | いつ来るか分からないごほうびは強い。ただし「はずれ」ばかりは疲れる | 大当たり・JACKPOT・押せ!!の熱さ。天井(ハマり救済)で長いはずれを作らない |
| 目標勾配(ゴールが近いほど頑張る) | 残りが見えると続ける | 進み具合を数字で出す(衣装「JACKPOT 7/10」、実績、図鑑、塔の「次の加護 20階」) |
| 短・中・長の目標の重ね | 数秒〜数分〜数日の目標が同時にあると、どの瞬間もやることがある | 短=大当たり/ボス、中=エリアの主/仲間の加入/衣装、長=転生/塔/エンディング/2周目 |
| 新しさのペース(興味曲線) | 一定の間隔で「新しい物」が出ると飽きにくい。山と谷をつける | だいたい25ステージごとに エリア・主・会話・新要素(下の解放表) |
| 役割のちがい | 同じ強さの足し算だけだと選ぶ意味が無い | ツララ=装甲つらぬき、妖精=回復、雷鳥=敵の手を止める、剣士=かばう |
| 収集と完成 | そろえる楽しみ。ただし数だけ増やすと作業になる | 図鑑・遺物・衣装。衣装は少数で、1つずつ手に入れ方を変える |
| 見せびらかし・自己表現 | 自分だけの見た目は長く遊ぶ理由になる | 衣装、称号、筐体テーマ(性能は変えない) |

## 1b. 「また遊びたくなる」ための考え方(何回も戻ってきてもらう)
| 考え方 | 中身 | このゲームでは |
|---|---|---|
| 習慣の輪(きっかけ→行動→ごほうび) | 毎回同じ小さな手順があると、開くのが習慣になる | 開く → おみくじを引く(98o)・ログボ・遠征の受け取り・ミッション。どれも数秒で終わる |
| 自分で引く変動報酬 | 自動でもらうより、自分で引いた方がうれしい | おみくじは自分で引く(大吉/中吉/小吉)。勝手には付かない |
| やりかけ効果(ツァイガルニク) | 途中の物は気になって戻ってくる | 「次の目標」(98o)が、もうすぐ届く物を進み具合つきで見せる。遠征の残り時間 |
| 約束の時間 | 「あとで戻ると良いことがある」が戻る理由になる | 遠征(30分〜16時間)、ボーナスタイムのゴールデンタイム、おかえりボーナス |
| 積み上げたものへの愛着(投資) | 自分で育てた・選んだ物があるほど離れにくい | 衣装、音楽室で選んだ曲、育てた英雄、図鑑・遺物 |
| 自己ベストの更新 | 他人と比べなくても、昨日の自分を超えるのは楽しい | 最高ステージ、塔の階、RUSH の連チャン記録、ランキング |
| 終わりよければ(ピーク・エンドの法則) | 一番盛り上がった所と最後の印象で記憶が決まる | 山場=JACKPOT/エリアの主。やめる時に「次はこれ」が見える(次の目標) |
| あおらない | 「今やらないと損」は短期では効くが、疲れて離れる原因になる | おみくじは引かなくても損なし・連続日数が切れても罰なし・期間限定で急がせない |

毎日のきっかけは増やしすぎない(開くたびにやる事が5つも6つもあると義務になる)。今は ログボ(自動)・おみくじ・ミッション・遠征 の4つ。これ以上は足さず、中身を良くする。
