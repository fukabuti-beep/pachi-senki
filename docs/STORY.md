# パチ戦記 設定資料(物語・キャラクター)

台詞を足す・直す時は、必ずここに合わせる。口調のルールは tests/story.js が機械で確かめる(ここを変えたらテストも合わせる)。

## 世界
- 世界には「運」が満ちていて、運が光るほど人も英雄も強くなる。パチンコの玉 = 運の玉。大当たり = 運の光があふれること。
- 虚無の王 **ニヒラ** が世界の運を吸い込み、運の光を少しずつ消している(序盤に分かること)。
- 実は運を「消して」いたのではなく、奪った運の光を自分の中に **ため込んでいた**(火山の主の最期の言葉で気づく → 魔界の主・虚空で深まる)。
- 各エリアの主は、ニヒラの黒いもや(虚無の力)に操られている。倒すともやが抜け、正気に戻るものもいる(守護神・星喰いの騎士)。

## 3人の英雄(すべてオリジナル)
| | ホムラ(剣士) | シズク(魔法使い) | コハク(弓使い) |
|---|---|---|---|
| 色 | 赤橙 `#ff7a5a` | 紫 `#d29aff` | 緑 `#7dff9a` |
| 性格 | 熱血・単純・まっすぐ。考えるより先に動く。ちょっと抜けていて、ケガにも気づかない | 落ち着いた物知り。敵の正体や魔法の仕組みを説明する役。仲間を気づかう | よく気づく観察役。耳と目がいい(足音・気配・小さな変化)。素直で明るく、ホムラにツッコむ |
| 一人称 | 俺 | 私 | 僕 |
| 語尾 | 〜だ!/〜ぞ/〜だぜ/〜しな | 〜わ/〜ね/〜よ/〜わよ/〜の | 〜よ/〜ね/〜だ/〜だね/〜かな |
| 使わない | 僕・私・わ/わよ/わね/かしら | 俺・僕・だぜ・〜ぞ・〜な!(命令) | 俺・私・だぜ・わよ・わね・かしら |
| よく言う | 「殴りに行く」「燃えてきた」「任せとけ」 | 「油断しないで」「〜の証ね」「計算どおり」 | 「何かいる」「見えてた」「3人で」 |
| 大当たり時 | 叫ぶ(よっしゃ!!) | 喜ぶが落ち着いている(当たったわ!) | 素直にはしゃぐ(やった!) |

三人の関係: ホムラが先頭で突っ込み、シズクが知識で支え、コハクが気づいてツッコむ。互いを信頼している(ケンカはしない)。

## 敵の口調
- エリアの主は、操られている間は途切れ途切れ(「森が…静かに…なる…」)。正気に戻る者は穏やかに礼を言う。
- 冥府の魔将・虚無の王は尊大(「人間ども」「すべては無に還る」)。

| エリア(STAGE) | 到着(a) | 主を倒した時(b) | この時点で分かること |
|---|---|---|---|
| 1 新緑の草原(1〜25) | 旅立ち: 運が消えている/ニヒラのしわざ | 森の主: 操られていた・黒いもや | 主は操られている |
| 2 灼熱の砂漠(26〜50) | ホムラが暑がる/コハクが砂の下の足音に気づく | 大蠍の毒: シズクが解呪、ホムラは刺されたことに気づいてない | ホムラの抜けた性格 |
| 3 白銀の氷原(51〜75) | 寒さ。ホムラ「動けば温まる」→コハク「砂漠では暑いって文句言ってたのに」 | 氷の中の花: 呪いが解けた証 | 倒すと土地が戻る |
| 4 紅蓮の火山(76〜100) | 溶岩魔人はニヒラに力を与えられた | 奪われた光: 「ニヒラ様の光が…」→ 運を消すんじゃなく **ため込んでいる?** | 伏線① ため込み |
| 5 冥府の魔界(101〜125) | 魔王の領地、運の光がほとんど無い | 魔将「王は我より遥かに深い闇」 | 伏線② 王の深い闇 |
| 6 天空の聖域(126〜150) | 守護神はかつて人の味方 | 守護神が正気に戻り羽根をくれる | 操られた者は救える |
| 7 星降る宙域(151〜175) | 星を食べる騎士 | 騎士が星を返す「王を止めてくれ」 | 体験版はここまで |
| 8 終焉の虚空(176〜200) | ニヒラ「運など幻」 | b7: 「ため込んだ分、私たちは当て続けた」→ニヒラ「ため込んだ光が…あふれる…!」 → 最終章 f1「解き放たれる光」(完全版): 光が8つの土地へ帰る/ニヒラ「運など幻だと思っていた。だが温かい」 → エンディング(スタッフロール) | 伏線①②の回収 |

- 2周目(201〜)以降は「虚無はまた芽吹く」= 終わらない旅(やりこみ)。

## ルール
- 新しい台詞は、話す人の「一人称・語尾・使わない言葉」を守る。迷ったら上の表の「よく言う」に寄せる。
- 前に言っていないことを前提にしない(「〜って言ってたよね」は、実際に言った台詞にだけ使う)。
- 体験版(〜STAGE 175)だけで話が途切れないよう、STAGE 175 の撃破シーンは体験版でも出す。最終章は完全版。
