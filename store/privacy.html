パチ戦記 プライバシーポリシー

最終更新日: 2026年11月12日

「パチ戦記」(以下「本アプリ」)は、利用者の個人情報を収集しません。本ポリシーでは、本アプリが扱う情報について説明します。

1. 収集する情報

本アプリは、氏名・メールアドレス・位置情報・連絡先・写真・端末の識別子などの個人情報を収集しません。アカウント登録もありません。

2. 端末内に保存する情報

ゲームの進行状況(ゴールド・ステージ・強化レベル・設定など)は、利用者の端末の中にだけ保存します。この情報が開発者や第三者に送られることはありません。アプリを削除すると、保存されたデータも消えます。

3. 通信について(オンラインランキング)

ゲームのほとんどは端末の中だけで動きます。通信するのはオンラインランキングだけです。

  • ゲーム内でプレイヤー名を決めた場合に限り、自己ベストが更新されたときに「プレイヤー名」「記録(最高到達ステージ・最高連チャン・最高RUSHスコア・大当たり累計)」「端末ごとにランダムに作った識別用の文字列」を、開発者が用意したランキング用サーバー(Cloudflare Workers)に送ります。プレイヤー名を決めなければ記録は送りません。
  • ランキング画面を開くと、上位の一覧と自分の順位をサーバーから読み込みます。
  • サーバーには各ランキングの上位100件だけを保存し、ランキングの表示以外には使いません。プレイヤー名には本名や個人を特定できる名前を使わないでください。
  • 通信の際、通常のWeb通信と同じく IP アドレスなどが Cloudflare に送られます。詳しくは Cloudflare のプライバシーポリシー をご覧ください。
  • ランキングから自分の記録を消したい場合は、下の「お問い合わせ」からご連絡ください。

4. 広告・課金

現在の本アプリには、広告もアプリ内課金もありません。今後、見たい人だけが見るリワード広告や「広告削除」の購入を追加する場合は、使用するサービスと扱う情報を本ポリシーに追記し、更新日を変更します。

5. 子どもの利用

本アプリは個人情報を収集しないため、年齢にかかわらず個人情報が集められることはありません。ゲーム内の通貨はゲームの中だけのもので、現実のお金に換えることはできません。

6. お問い合わせ

本ポリシーについてのお問い合わせは、開発者の BOOTH ショップ(https://fukabuchi.booth.pm/)のメッセージ機能からお願いします。

Privacy Policy (English)

"Pachi Senki" does not collect personal information. Game progress is stored only on your device. The only network feature is the online leaderboard: only if you set a player name, your player name, best scores and a random device identifier are sent to the developer’s leaderboard server (Cloudflare Workers), which keeps the top 100 entries per board for display only. Opening the leaderboard downloads the top list. As with any web request, your IP address is visible to Cloudflare. The app currently contains no ads and no in-app purchases; if these are added, this policy will be updated. Contact: https://fukabuchi.booth.pm/
